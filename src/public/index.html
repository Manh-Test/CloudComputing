Thống Kê & Tài Liệu API

Danh sách RESTful APIs được hỗ trợ bởi Node.js Backend & Công cụ gửi Yêu cầu Trực tiếp

Thử Nghiệm API Trực Tiếp (Interactive API Console)

Status: - Time: - 
Response JSON sẽ hiển thị ở đây...
GET
/api/employees

Lấy danh sách tất cả nhân viên. Hỗ trợ query search, department, status.

GET
/api/employees/departments/stats

Lấy thống kê tổng hợp số lượng nhân viên, tổng quỹ lương và lương trung bình từng phòng ban.

GET
/api/employees/:id

Lấy thông tin chi tiết của 1 nhân viên theo ID.

POST
/api/employees

Thêm mới nhân viên. Yêu cầu JSON Body: fullName, email, department, position, salary, status.

PUT
/api/employees/:id

Cập nhật thông tin nhân viên theo ID.

DELETE
/api/employees/:id

Xóa bản ghi nhân viên theo ID khỏi cơ sở dữ liệu.

GET
/health

Kiểm tra kết nối trực tiếp từ Node.js Backend đến SQL Server DB.
